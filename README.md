# Summary and Skills

This project uses PyTorch to build and train a neural network that classifies handwritten digits from the MNIST dataset.

Skills demonstrated:

- Python
- PyTorch
- Neural networks
- Data preprocessing
- DataLoaders
- Model training and evaluation
- Backpropagation
- Accuracy calculation
- Data visualisation with Matplotlib

# Aim of the Project

The aim of this project is to train a neural network to recognise handwritten digits from `0` to `9` using the MNIST dataset.

The model takes `28 × 28` grayscale images as input and predicts the corresponding digit class.

# Limitations

- The model uses a simple fully connected neural network rather than a CNN, which is better suited to image classification.
- The project uses MNIST, a relatively simple and well-structured dataset.
- Model performance is mainly evaluated using accuracy.
- Limited hyperparameter tuning was performed.
